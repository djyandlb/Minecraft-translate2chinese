# M4 地图汉化 实施计划

> **给代理工作者：** 必需子技能：使用 superpowers:subagent-driven-development 逐任务实施。步骤用复选框（`- [ ]`）跟踪。

**目标：** 地图存档汉化——整档复制 → 在副本上全范围 NBT 文本扫描/翻译/写回 → 输出汉化副本（文件夹 + 可选 mcworld zip），**原档只读不动**。

**架构：** 新增 `backend/app/maps/` 包（world 识别 / copy 整档复制 / scan NBT 扫描 / write 写回 / export 输出），翻译引擎复用 M2 的 `create_engine` + `MemoryStore` + `glossary`。前端加地图页（或复用现有向导加"地图"模式）。`.mca` 区块解析优先验证 `anvil-parser` 库，不兼容则字节级 hack（仅未压缩区块）+ 记录局限。

**技术栈：** `nbtlib`（NBT 读写）、`anvil-parser`（区块，待验证）、现有 app 模块（engine/memory/glossary/main）。

## 全局约束

- **原档只读**，一切写入只发生在副本（`maps/copy.py` 复制后）
- NBT 读：`nbtlib.File.load(path, gzipped=True)`；写回：`save()`（原格式保留）
- 扫描键白名单放 `maps/scan_keys.json` 可配置，默认含：`Command`、`CustomName`、`Name`、`front_text`/`Text1..Text4`（告示牌）、`pages`（书与笔）、`title`/`author`（书）
- 数据包侧：`data/**/*.json`（进度/成就）与 `.mcfunction`（say/tellraw/title）
- `.mca` 区块：anvil-parser 可用则解析 NBT；否则字节级 hack（记录局限）
- 写回策略：NBT `String` 值内替换 + JSON 文本 `text` 键替换（借鉴 MCC-i18n 思路，MIT 可复用思想）
- 翻译流程复用 M2：`create_engine` + 先查 `MemoryStore` + 目标语言参数化 + `is_same_script` 简繁捷径
- 全程 `pathlib`、中文注释/提交、UTF-8、不打包


**NBT 递归核心**（`scan_nbt`，Compound/List 遍历，String 值命中白名单键则收集）：
```python
def scan_nbt(data, path_str: str = "", acc: list | None = None) -> None:
    if isinstance(data, Compound):
        for k, v in data.items():
            if isinstance(v, String) and k in keys:
                acc.append({"text": str(v), "nbt_path": f"{path_str}.{k}", "key": k})
            else:
                scan_nbt(v, f"{path_str}.{k}", acc)
    elif isinstance(data, List):
        for i, item in enumerate(data):
            scan_nbt(item, f"{path_str}[{i}]", acc)
```

**步骤：** TDD——构造含 Command/CustomName 的 NBT 文件，scan_file 命中；.mca 分支先写"验证 anvil-parser"子任务（`pip install anvil-parser`，可 import 则用，否则字节级记录局限）；提交 `feat: 地图 NBT 扫描`
