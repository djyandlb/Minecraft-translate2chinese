使用说明 · 全流程 ▼

① 首次进入：配置翻译引擎

  1. 选择翻译引擎：DeepSeek / 通义 / Kimi / Ollama / 免费 API
  2. 填写接口地址、模型名、API Key（仅保存在本机）
  3. 「测试连接」确认可用 → 选择目标语言（简中 / 繁中）→ 保存

② 拖入文件开始翻译

  1. 将整合包 / Mod / 地图 / 光影拖入左侧虚线区
  2. 自动识别类型，社区词库优先命中，点击「开始翻译」
  3. 已自带中文的 Mod 自动跳过，不重复翻译

③ 查看产物

  1. 完成后点「打开产物文件夹」
  2. 整合包产物含汉化资源包、i18n 模组、VP 硬编码补丁
  3. 中断过的项目：启动时自动检测，可断点续联
