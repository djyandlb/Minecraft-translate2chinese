# 像素译站 · Pixel Translation Station

Minecraft 整合包 / Mod / 地图 / 光影的 AI 一键汉化工具。

拖入文件 → 自动识别 → AI 翻译 → 质量审查 → 生成可用的汉化产物。全程可视化。

免费开源 · Windows 桌面应用。

---

## 项目简介

像素译站是一款面向 Minecraft 玩家的 AI 辅助汉化工具，支持**整合包、单个 Mod、地图存档、光影包**四种输入类型，自动完成文本提取、翻译、质量审查与产物生成，全程无需手动编辑文件。

---

## 功能特性

- **全类型汉化**：整合包 / Mod / 地图 / 光影一键处理
- **AI + 社区词库双通道**：CFPA 社区人工词库优先命中，缺口才走 AI
- **全文本覆盖**：语言文件、教程书、任务书、进度、KubeJS 脚本、字节码硬编码
- **三级质量审查**：初审 → 强制重翻 → 终审，杜绝纯英文残留
- **断点续联**：中断后重新拖入同文件即可继续，已翻译不重复
- **自动识别**：输入类型、源语言、Minecraft 版本自动判定，产物格式无需手动设置

## 快速开始

### 1. 下载

[GitHub Releases 下载最新版](https://github.com/djyandlb/Minecraft-translate2chinese/releases/latest)

| 安装包 | 说明 |
|--------|------|
| `release-v1.3.2-portable.exe` | 便携版：双击即用，无需安装，随身携带 |
| `release-v1.3.2-setup.exe` | 安装版：安装向导，正式部署 |

### 2. 使用步骤

1. 启动应用，首次运行自动弹出设置窗口
2. 选择翻译引擎并配置 API Key，点击「测试连接」验证可用
3. **点「动态测试吞吐」校准档位**（强烈建议：约 30-60 秒——RPM 校准要灌满一个 60s 限流窗口才测得准；自动定位并发/批次/扫描。否则按默认保守档跑，API 可能跑不满、偏慢）
4. 拖入需要汉化的整合包 / Mod / 地图 / 光影（支持多个，队列逐项处理）
5. 点击「开始翻译」
6. 完成后点击「打开产物文件夹」，将产物放置到对应位置

> 源语言自动识别，无需手动指定。

### 3. 性能与吞吐校准（重要）

- **预算闸（每分钟请求预算 RPM）**：默认 **0 = 自动校准**——程序会自学习你所用 API 的限流配额（撞到限流自动退、稳定自动升），每个 API 都能稳跑满速，**无需手动填写**；想精确控制的高手可在设置页填具体 RPM 值。
- **必做「动态测试吞吐」**：首次使用、或换用新 API 时强烈建议点一次「动态测试吞吐」，它会自动定位该 API 的最优并发/批次/扫描并填好滑块——**不做这一步虽然能用，但可能跑不快 / 会卡**（预算闸未匹配到 API 真实吞吐）。
- 预算闸机制（业界标准）：请求在**发送前**按配额放行，超配额的本地排队——API 永不触发 429 限流，也就不会退避重试、降档卡死。

## 翻译质量与限制

翻译质量取决于所选 AI 模型。**本软件不对翻译结果作任何准确性保证。**

| API / 模型 | 质量参考 |
|-----------|---------|
| 商业大模型（DeepSeek / 通义 / Kimi 等） | 高：准确、流畅、贴合语境 |
| 免费 API | 中：限量限速 |
| 在线机翻（Google） | 中低：免费、直译为主，无 AI 语境理解 |

- 语言文件中 CFPA 社区词库覆盖的部分为社区人工翻译，与 API 无关
- 翻译结果可能存在错译、漏译、机翻腔，重要内容请自行核对

## 开发与构建

### 环境要求
- Python 3.14
- Node.js 18+ 与 npm
- PyInstaller（打包）
- Inno Setup 6（安装版）

### 后端
```bash
cd backend
pip install -r requirements.txt
python -m pytest tests/ -q
uvicorn app.main:app --port 8000
```

### 前端
```bash
cd frontend
npm install
npm run build
```

### 一键打包（Windows）
```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_all.ps1
```

产物位于 `dist/便携版/` 与 `dist/安装版/`。
